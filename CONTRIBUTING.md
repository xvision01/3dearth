# Contributing to 3D Earth Explorer

Thanks for helping improve 3D Earth Explorer!

## Getting started

1. Fork or clone the repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Make your change and test it locally.
5. Run `npm run build` before opening a pull request.

## Pull requests

Please keep pull requests focused on one improvement or fix. Include a short description of what changed and how you tested it.

## Ideas for contributions

- Accessibility improvements
- Performance optimizations
- Better country and geography data
- Mobile UI improvements
- New exploration or comparison features
